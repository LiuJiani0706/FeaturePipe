# 下一步实验

1. 先用已获授权的脱敏材料运行 1 篇，记录调用数、服务端 usage、运行时长和失败阶段，再扩展到完整语料。不要把 mock 结果当作模型评测。
2. 做单次写作、全文核查、逐句核查、五轮逐句核查四组消融；固定材料和标题，参考正文只用于评测，禁止送入生成上下文。
3. 对时间线、人名归属、引语和无依据场景分别标注错误，报告每千字错误数、核查精确率/召回率、修订引入新错误及人工编辑时间。每组多次运行，盲评并报告分歧。
4. 多 agent 可将事实核查、叙事编辑、伦理与人物表征分开独立审阅，最终由单一编辑顺序合并；先验证收益，再承担新增成本。独立角色不代表独立事实来源。
5. 低成本版可用检索定位证据后核查，并缓存不变素材；忠实复刻版应保留完整上下文逐句检查。二者须分别报告，不能将优化版冒充原论文配置。
